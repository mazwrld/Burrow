# Burrow glossary

One name per idea. Buttons, menus, titles, tooltips and errors use these words.

## Things

| Term | Means | Not |
| --- | --- | --- |
| Mole | The `mo` command line tool Burrow runs | CLI, backend, engine |
| Health | The page with disk, memory, CPU, battery and top processes | Status, dashboard, monitor |
| Health score | Mole's 0–100 number for the Mac, with its message | rating, grade |
| Clean | The page that previews and runs `mo clean` | Cleanup, Cleaner |
| Preview | A run of `mo clean --dry-run` that changes nothing | scan, dry run (in the UI), simulate |
| Group | One `=== … ===` section of the preview, such as "User essentials" | category, section |
| Item | One path in a group, with its size | entry, file, row |
| Not cleaned by this run | Large files and project folders Mole only reports | suggestions, advice |
| History | The page listing every Mole run | log, activity |
| Run | One Mole command in History, with its date and size | session (code only), job |
| Space | The page that shows what uses the disk (M2) | Analyze, disk explorer |
| Apps | The page listing installed apps (M2) | Uninstall, applications |
| Admin cleanup | The part of `mo clean` that needs an administrator password | system cleanup, sudo |

## Actions

| Term | Means | Not |
| --- | --- | --- |
| Preview | Run a preview | Scan, Analyze, Dry Run |
| Clean | Run `mo clean` for real; files are deleted for good | Delete, Purge, Remove, Run |
| Stop | Interrupt the running Mole command | Cancel (Cancel only closes a dialog), Abort |
| Refresh | Read the page from Mole again | Reload, Update |
| Open in Terminal | Start a Mole command in a new Terminal window | Run in Terminal, Launch |
| Copy Command | Copy the exact Mole command | Copy |
| Reveal in Finder | Show an item in Finder | Open, Show |
| Try Again | Run a Mole command that failed again | Retry |
| Check Again | Look for Mole again on the setup page | Retry, Reload |
| Deleted | Removed for good | Removed, Cleaned (as a result) |
| Moved to Trash | Removed but recoverable from the Trash | Trashed |
